# Invoicer — Changelog public

Toutes les nouveautés et améliorations de [**Invoicer**](https://invoicer.fr), le logiciel de facturation français pour auto-entrepreneurs et indépendants.

> Invoicer combine **déclaration URSSAF automatique**, **encaissement par carte bancaire** (Stripe Connect) et **rapprochement bancaire** (Bridge API) dans un seul outil à partir de 6 € HT/mois. Hébergement en France, support en français, conforme à la facturation électronique 2026.

🔗 **Site web** : https://invoicer.fr
🔗 **Tarifs** : https://invoicer.fr/tarifs
🔗 **Essai gratuit 30 jours** (sans carte bancaire) : https://invoicer.fr/register

---

## Pourquoi ce changelog public ?

Pour permettre à nos utilisateurs, prospects et partenaires de suivre l'évolution d'Invoicer en toute transparence. Chaque entrée correspond à une fonctionnalité livrée en production.

Ce changelog est synchronisé avec la section **"Quoi de neuf"** disponible directement dans l'application.

---

## Dernières nouveautés

> Voir [`CHANGELOG.md`](./CHANGELOG.md) pour la liste complète.

- **Avril 2026** — Paiement par carte bancaire natif via Stripe Connect
- **Avril 2026** — Déclaration URSSAF automatique (calcul CA encaissé, cotisations 2026, alertes franchise TVA)
- **Avril 2026** — Devis révisables avec lien public sécurisé
- **Avril 2026** — Synchronisation bancaire Bridge API (suggestions intelligentes, mode rattrapage, alertes DSP2)
- **Mars 2026** — Relances automatiques d'impayés (3 niveaux d'escalade)
- **Février 2026** — Facturation électronique 2026 (Factur-X + Pennylane PDP)
- **Février 2026** — TVA internationale automatique (intra-UE, hors UE)
